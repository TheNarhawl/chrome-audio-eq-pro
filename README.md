# FlatEQ & Volume Booster Pro (Manifest V3)

Персональное расширение для Google Chrome с усилением громкости до 1000%, защитным Brickwall-лимитером, 10-полосным параметрическим эквалайзером (`peaking`), анализатором спектра в реальном времени и облачной синхронизацией пресетов.

## Архитектура
- **`popup.html / popup.js / popup.css`** — интерфейс в стиле строгого Flat-дизайна (400×600 px), отрисовка FFT-спектра и кривой АЧХ на `<canvas>`, управление пресетами в `chrome.storage.sync`.
- **`service-worker.js`** — координатор жизненного цикла: инициализирует `offscreen` документ, запрашивает `streamId` через `chrome.tabCapture.getMediaStreamId`, обновляет бейдж громкости и освобождает ресурсы при закрытии вкладки.
- **`offscreen.html / offscreen.js`** — изолированный аудио-движок, хранящий независимые пайплайны `Map<tabId, TabAudioPipeline>` для одновременной работы в нескольких вкладках.

## Установка и тестирование
1. Создайте папку `chrome-audio-eq-pro` и поместите в неё все 7 файлов (`manifest.json`, `service-worker.js`, `offscreen.html`, `offscreen.js`, `popup.html`, `popup.css`, `popup.js`).
2. Откройте в браузере страницу `chrome://extensions/`.
3. Включите переключатель **Режим разработчика (Developer mode)** в правом верхнем углу.
4. Нажмите **Загрузить распакованное расширение (Load unpacked)** и выберите созданную папку.
5. Откройте любой сайт с аудио/видео (например, YouTube, SoundCloud, Twitch), откройте расширение и передвиньте ползунок громкости или выберите пресет эквалайзера.

## Известные ограничения платформы
1. **Защищённые страницы браузера:** На вкладках `chrome://`, `chrome-extension://` и в Магазине расширений Chrome (`chromewebstore.google.com`) API `tabCapture` заблокирован политикой безопасности браузера.
2. **Аппаратный DRM (Widevine L1):** Потоки с программным декодированием (Widevine L3 — большинство браузерных версий Spotify, Netflix, Кинопоиск в Chrome на ПК) перехватываются штатно. Однако при активном аппаратном DRM уровня L1 (Hardware Secure Decryption на некоторых конфигурациях Windows Media Foundation) аудиопоток идёт напрямую в аудиодрайвер ОС в обход микшера Chromium.
3. **Индикатор захвата вкладки:** Пока активен `tabCapture`, Chrome отображает синюю иконку захвата на вкладке и отключает возможность переводить эту вкладку в режим Chromecast до нажатия кнопки отключения перехвата (иконка Power в шапке расширения).
