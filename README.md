## 📌 О проекте

**FlatEQ & Volume Booster Pro** — производительное персональное расширение без внешних зависимостей и сборщиков, решающее ключевые задачи цифровой обработки звука в браузере:

* **Преодоление аппаратного лимита 100%:** расширение динамического диапазона от 0% до 1000% (0.0x – 10.0x) без зажатия на нативном ограничении `HTMLMediaElement.volume`.
* **Обход ограничений CORS и закрытых DOM:** аудиопоток захватывается на уровне выходного микшера вкладки через `chrome.tabCapture`, что исключает появление *tainted audio* на YouTube, Twitch, SoundCloud, Spotify Web и стриминговых платформах.
* **Защита тракта от перегруза:** подключаемый Brickwall-лимитер на базе `DynamicsCompressorNode` срезает опасные пики при экстремальном усилении (>300%).
* **Энергоэффективный Flat UI:** строгий плоский интерфейс (400×600 px) без теней и градиентов с нулевым потреблением ресурсов процессора в фоновом режиме.

## ✨ Ключевые возможности

| Функция | Описание |
| :--- | :--- |
| **Усиление 0% – 1000%** | Плавная регулировка ползунком, числовой ввод с клавиатуры и пресетные кнопки быстрого выбора (100%, 200%, 300%, 500%, 1000%). |
| **10-полосный эквалайзер** | Полноценные peaking-фильтры стандарта ISO: `31, 62, 125, 250, 500, 1k, 2k, 4k, 8k, 16k Гц` с шагом регулировки `±12 дБ`. Двойной клик сбрасывает полосу в 0 дБ. |
| **Realtime АЧХ-анализатор** | Рендеринг спектра частот (FFT) поверх расчетной кривой эквализации на HTML5 Canvas. |
| **Антиклиппинг (Лимитер)** | Компрессор жесткого профиля (`threshold: -1 dBFS`, `ratio: 20:1`, `attack: 1 ms`, `release: 60 ms`) для чистого звука на высокой громкости. |
| **Zero-Zipper-Noise** | Модуляция узлов через экспоненциальное сглаживание `AudioParam.setTargetAtTime()`, устраняющее цифровой треск при перемещении регуляторов. |
| **Облачные пресеты (Sync)** | Сохранение, переименование и удаление собственных пресетов в боковой панели (Side Drawer) с синхронизацией через `chrome.storage.sync`. |
| **Двухсторонняя тема** | Полноценный Flat Dark Mode по умолчанию и светлая тема с сохранением пользовательского выбора. |

## 🏗️ Архитектура и звуковой тракт

В **Manifest V3** фоновые страницы заменены на кратковременный `Service Worker`, лишенный доступа к DOM и Web Audio API. Обработка звука вынесена в изолированный **Offscreen Document**, сохраняющий независимый реестр `Map<tabId, TabAudioPipeline>` для одновременной работы на нескольких вкладках:

```
Вкладка (Звук)
      │
      ▼  [chrome.tabCapture.getMediaStreamId + getUserMedia]
┌────────────────────────────────────────────────────────────────────────┐
│                   Offscreen Document Audio Pipeline                    │
│                                                                        │
│  [MediaStreamAudioSourceNode]                                          │
│             │                                                          │
│             ▼                                                          │
│        [GainNode] (0.0x – 10.0x)                                       │
│             │                                                          │
│             ▼                                                          │
│  [10x BiquadFilterNode] (Peaking: 31Hz ... 16kHz, Q=1.41)              │
│             │                                                          │
│             ├── [Лимитер ВКЛ] ──► [DynamicsCompressorNode] ──┐         │
│             │                                                │         │
│             └── [Лимитер ВЫКЛ] ──────────────────────────────┼──┐      │
│                                                              │  │      │
│                                                              ▼  ▼      │
│                                                       [AnalyserNode]   │
│                                                              │         │
│                                                              ▼         │
│                                                    [audioCtx.destination]
└────────────────────────────────────────────────────────────────────────┘
                                                               │ (IPC Port)
                                                               ▼
                                                      [Popup Canvas Render]
```

> **Энергоэффективность:** Порт передачи данных спектра (`visualizer-port`) открывается только при развернутом Popup. При закрытии окна стриминг кадров останавливается, снижая нагрузку на процессор до нуля.

## 🚀 Пошаговая установка

### 1. Подготовка файлов
Склонируйте репозиторий или сохраните файлы проекта в локальную папку:
```bash
git clone https://github.com/your-username/chrome-audio-eq-pro.git
cd chrome-audio-eq-pro
```

### 2. Генерация PNG-иконок
1. Убедитесь, что файл `icons/icon.svg` находится на месте.
2. Откройте файл `generate-icons.html` двойным кликом в браузере Chrome.
3. Нажмите кнопку **«Скачать все иконки (PNG)»**.
4. Скопируйте полученные файлы `icon16.png`, `icon32.png`, `icon48.png` и `icon128.png` в папку `icons/`.
5. *(Опционально)* Файл `generate-icons.html` можно удалить после генерации.

### 3. Загрузка в Google Chrome
1. Откройте браузер и перейдите по адресу:
   ```text
   chrome://extensions/
   ```
2. В правом верхнем углу включите тумблер **Режим разработчика** (*Developer mode*).
3. В появившемся меню слева нажмите кнопку **Загрузить распакованное расширение** (*Load unpacked*).
4. Выберите корневую папку проекта `chrome-audio-eq-pro`.
5. Расширение установлено и готово к работе! Закрепите его иконку на панели инструментов для быстрого доступа.

## 💡 Использование и горячие действия

* **Регулировка звука:** Перемещайте верхний ползунок или введите точное число (от `0` до `1000`).
* **Сброс эквалайзера:** Нажмите кнопку `Сброс 0 dB` на панели либо дважды кликните по конкретному ползунку частоты для сброса одиночной полосы.
* **Управление пресетами:**
  * Выберите один из готовых жанровых профилей в выпадающем списке (`Flat`, `Bass Boost`, `Vocal`, `Rock`, `Electronic`, `Podcast`).
  * Нажмите кнопку `Пресеты`, введите имя в поле ввода и нажмите `Сохранить`, чтобы записать текущую связку Gain + EQ в облако `chrome.storage.sync`.
* **Смена темы:** Нажмите на иконку Луны/Солнца в верхнем правом углу для переключения между темным и светлым режимами.
* **Отключение захвата:** Нажмите на иконку питания в верхней панели — расширение освободит системный аудиопоток вкладки и вернет стандартный вывод звука Chrome.

## ⚠️ Известные ограничения платформы Chromium

1. **Системные страницы браузера:** Согласно политике безопасности Chromium, API `tabCapture` программно заблокирован на служебных страницах (`chrome://`, `chrome-extension://`, `view-source:`) и на сайте интернет-магазина Chrome Web Store.
2. **Аппаратный DRM (Widevine L1):** Защищенный медиаконтент с аппаратной расшифровкой ОС (некоторые конфигурации Windows Media Foundation) декодируется в защищенном видео-пайплайне в обход аудиомикшера вкладки. Потоки со стандартным веб-декодированием (L3) обрабатываются штатно.
3. **WebRTC и эхоподавление (AEC):** При звонках в веб-сервисах (Google Meet, Discord) форсирование звука выше 300% через динамики ноутбука может триггерить нативное эхоподавление браузера. При экстремальном бусте рекомендуется использовать наушники.
4. **Полноэкранный режим:** Во время активного захвата вкладки полноэкранный режим плееров открывается в границах окна браузера, чтобы индикатор записи Chromium оставался на виду. Для перехода в честный полный экран на весь монитор используйте клавишу `F11`.
